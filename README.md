## Development Workflow

The FPGA projects generally follow this engineering process:

1. Review the lab requirements.
2. Identify the required inputs and outputs.
3. Design the digital logic.
4. Create the project in Quartus Prime Lite.
5. Build the schematic or HDL design.
6. Assign FPGA pins.
7. Compile the project.
8. Resolve compilation errors.
9. Program the DE10-Lite FPGA board.
10. Test the physical inputs and outputs.
11. Troubleshoot unexpected behavior.
12. Verify the final hardware operation.
13. Document the project using screenshots and hardware photos.
